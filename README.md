# Observaciones

Me tome la libertad creativa de permitir "Otro" tipo de mascota para ofrecer en adopción, principalmente para poder poner fotos de distintos animales, esto se ve reflejado de manera correcta en las estadísticas y a mi parecer no afecta la complejidad del proyecto.

Se acepta tambien el formato de números de teléfono de +569XXXXYYYY

Cuento con algunos conocimientos previos de CSS :)

El sistema de agregar archivos para fotos en el formulario quedo más parecido al sistema utilizado en u-cursos (ofrece para añadir más archivos a medida que se van añadiendo, manteniendo el tope de 5 fotos) que al descrito por el enunciado (botón para añadir otro archivo), esto al encontrar que la implementación del enunciado no era lo optimo para mi estilo de botones.
